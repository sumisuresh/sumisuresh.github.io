# Upload the revised four-area website files

Destination: **sumisuresh/sumisuresh.github.io**.

1. Extract `Website_Research_Visuals_DualHTR_Update.zip`.
2. Open your website repository and choose **Add file → Upload files**.
3. Upload these four HTML files and the stylesheet, keeping their paths:

   - `index.html`
   - `research.html`
   - `cv.html`
   - `contact.html`
   - `assets/site.css`

4. Commit the changes and wait for GitHub Pages to deploy.

You do not need to upload this instructions file. Your existing
`assets/gif.gif`, research illustrations, profile image and other assets are
used by these pages; keep them in the repository.

## CV PDF links

The Home, CV and Contact pages have their PDF links commented out. The CV page
still displays the academic overview, without a PDF download or open button.

**Commenting out a link does not make the PDF private.** The original PDF is
still in the public repository and can be opened through its direct URL. To
stop the current version being served, remove `assets/Sumi_Suresh_CV.pdf` from
the published repository, or replace it with a version without your phone
number. Existing copies and repository history may remain available.

The PDF itself is not included or altered by this update package.
